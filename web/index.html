LNBITS GERTY

Gerty web installer

Install Gerty firmware on your display over USB, then configure Wi-Fi and the Gerty API URL from the LNbits Gerty extension.

Use desktop Chrome or Edge and a USB data cable. Close other serial monitors before connecting.

01 / INSTALL

Install Gerty firmware

Check the model printed on your board. The three S3 displays use different firmware despite sharing a chip.

Checking firmware…

Installing firmware erases saved settings. Configure again afterwards. Close the install dialog before continuing below.

02 / CONFIGURE

Configure Wi-Fi and Gerty

Connect your display over USB to save its Wi-Fi credentials and Gerty API URL. Settings are stored on the display.

Already configured? Press RST, then connect within 60 seconds. A new display waits for setup indefinitely. After saving, the display restarts and loads the saved settings.

Use a 2.4 GHz network. Enter its name exactly, including capital letters.

Leave blank only for an open network. Otherwise use 8–63 bytes.

Set up a Gerty device in the LNbits Gerty extension and paste its Gerty API URL here. Use the base pages URL, without a page number. Use a server address your display can reach, not localhost. Set the feed’s image size to match the selected display.

Not connected.

03 / DEBUG

Serial monitor

Live device output at 115200 baud. Connect above to view logs. LilyGO disconnects when it sleeps.

Logs may contain your private Gerty API URL. Review them before sharing.


Device not connecting?
  • Try a USB data cable; charging-only cables won’t work.
  • Close the installer dialog and any other app using the serial port.
  • For installation: hold BOOT, press and release RST, then release BOOT.
  • For configuration: press RST without holding BOOT, then reconnect. A USB port may reappear under a new name.
  • A “saved” message confirms storage. Check the logs after restart to verify Wi-Fi and image downloads.
